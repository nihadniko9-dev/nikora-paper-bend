# NIKORA — نیکۆرا

Approved personal umbrella brand of Nihad Jiad Yousef.

Products: **Nikora Sub**, **Nikora Tracker**, **Nikora Easing Lab**, **Nikora Paper Bend**.
Use NIKORA for the parent brand and Nikora + product name for applications.
Preserve the author's attribution and all third-party licenses.

Shared visual direction: deep green background (#111510), layered panels
(#1B2119), lime accent (#BBD755), off-white text (#F1F4EB), Segoe UI typography.
Machine-readable tokens are in nikora-brand.json. Product-specific layouts
can vary while keeping these foundations consistent.

Compatibility: existing package IDs, saved-project keys, CLI commands,
repository URLs and installation paths remain valid. The new display name
does not rename these identifiers or retroactively replace published binaries.

CAPNI × NS is a client/company project and retains its existing identity.
